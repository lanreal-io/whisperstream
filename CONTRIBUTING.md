# Contributing

Thanks for your interest in Whisperstream. Bug reports and feature ideas are
welcome in [GitHub Issues](https://github.com/lanreal-io/whisperstream/issues/new/choose).
Please search existing issues first.

I'm not accepting pull requests right now. If you've found a fix, open an issue
and describe it. You're welcome to fork Whisperstream and change it under the
GPL-3.0-only licence.

Whisperstream is a spare-time project. I look at issues when I can, but I can't
promise a response time, a fix or a release schedule. Report security problems
privately as described in [SECURITY.md](SECURITY.md).

## Building from source

See the [README](README.md) to build and run Whisperstream from source.
